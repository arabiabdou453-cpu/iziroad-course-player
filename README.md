# IZIROAD — LMS Course Player & Dashboard Clone

استنساخ مطابق وتفاعلي بنسبة 100% لواجهة مشغل الكورسات ولوحة التحكم الخاصة بمنصة **IZIROAD** (*Web design with WordPress 2026*).

## 🌟 المميزات والخصائص / Features

1. **مشغل الكورسات المتقدم (Player View)**:
   * شريط علوي مع اسم الدورة وزر "Complete the Course".
   * شريط جانبي مع نسبة الإنجاز التفاعلية وقائمة بجميع الدروس ومُددها الزمنية.
   * مشغل فيديو متطور مع صورة المدرب الدائرية (Webcam PiP Overlay) كما في المنصة الأصلية.
   * شريط تحكم كامل بالفيديو (تشغيل، إيقاف، شريط التمرير، الوقت، ملء الشاشة، وكتم الصوت).
   * تبويبات سفلية: **Résumé** (ملخص الدرس والوسوم)، **Notes** (نظام تدوين ملاحظات شخصي يحفظ تلقائياً في المتصفح LocalStorage)، **Commentaires** (نظام تعليقات ونقاش حي).
   * زر "Terminé" لتحديد الدرس كمكتمل وزر "Suivant >" للانتقال التلقائي للدرس التالي.

2. **صفحة تفاصيل الدورة (Overview View)**:
   * ترويسة IZIROAD الكاملة مع روابط المجتمع، الكورسات، والمدونة، وحساب المستخدم الشخصي (**Arabi Abderrahmane**).
   * شريط جانبي للوحة التحكم (Mes cours, Mes achats, Déconnexion).
   * أكورديون تفاعلي لمحتوى الكورس وسياسات الاسترجاع.
